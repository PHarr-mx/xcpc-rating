## 1. 分期计划

| 期 | 内容 | 结束标志 | 状态 |
|----|------|----------|------|
| **一期 · 地基** | `pyproject.toml` 统一打包（✅）、建表（✅）、JSON 一次性迁移（✅）、Reflex 骨架、`/` 榜单只读页 | 能用真实数据看到榜单 | 🔄 进行中（打包/建表/迁移完成，Reflex 骨架未开始） |
| **二期 · 认证** | 接入 `reflex-local-auth`、角色与绑定审批、`/profile`、审计日志 | 权限三处校验点立稳 | ⬜ 未开始 |
| **三期 · 管理后台** | 选手/队伍 CRUD、xlsx 在线导入 + 交互式匹配 | 不再需要敲 CLI 导入 | ⬜ 未开始 |
| **四期 · 业务补齐** | 训练赛录入、Rating 计算器实现、权重试算页、图表 | 榜单数值有业务含义 | ⬜ 未开始 |
| **五期 · 上线** | systemd + Caddy + 备份 cron | 公网可访问 | ⬜ 未开始 |

## 2. 两条顺序约束

- **一期必须最先**。包结构不统一，后面每步都在跟 PYTHONPATH 打架。
- **二期必须在三期之前**。否则会先做出一批无认证的写接口。

## 3. 各期详细内容

### 一期 · 地基

- ✅ `pyproject.toml` 统一打包（uv + `.python-version`=3.13.14），`backend/data/*` 迁入 `xcpc_core/`
- ✅ SQLite 建表（`xcpc_core/db/tables.py`，纯 SQLAlchemy）+ store 重构为 repository + `migrate` 灌数据（24 选手/8 队伍/1 比赛，幂等）
- ⬜ Reflex 骨架 + `/` 榜单只读页（按 [08](08-前端与Web交互模块.md) §2.2 BoardState）
- **开发要点与坑**见 [12](12-开发流程建议.md) §5

### 二期 · 认证

- 接入 `reflex-local-auth`，`UserProfile` / `BindingRequest` 表（[09](09-认证与权限模块.md) §5）
- 三角色、字段级权限、权限三落点（[09](09-认证与权限模块.md) §3/§4）
- `/profile` 自助改资料、审计日志
- **完成标志**：权限三处校验点立稳

### 三期 · 管理后台

- 选手/队伍 CRUD 页面（`/admin/players` `/admin/teams`）
- xlsx 在线导入 + 交互式匹配（`/admin/import`，`ImportBatch` staged → 确认，见 [04](04-数据导入与加工模块.md) §5）
- **完成标志**：不再需要敲 CLI 导入

### 四期 · 业务补齐

- 训练赛录入（`training` 数据源，[03](03-比赛与记录模块.md) §4）
- Rating 计算器实现：`BaseRatingCalculator` 继承体系，MVP placeholder（[06](06-Rating计算模块.md)）
- 权重试算页 `/admin/rating`（[08](08-前端与Web交互模块.md) §4.5）
- 图表（Plotly Rating 曲线）
- **完成标志**：榜单数值有业务含义

### 五期 · 上线

- systemd + Caddy + 备份 cron（[11](11-部署与运维.md)）
- **完成标志**：公网可访问

## 4. 每期进入 / 退出检查

| 期 | 进入前必须 | 退出时产出 |
|----|-----------|-----------|
| 一期 | 现有测试全绿 | pyproject、DB 表、迁移脚本、只读榜单页 |
| 二期 | 一期已上线（本机可跑） | 可登录、可绑定、权限校验生效 |
| 三期 | 二期认证完成 | 全部写操作可在 Web 完成 |
| 四期 | 三期完成 | Rating 有业务含义、权重可试算 |
| 五期 | 四期完成 | 公网可访问 + 备份可用 |
