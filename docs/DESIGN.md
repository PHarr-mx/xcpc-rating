# xcpc-rating 项目设计

校内 XCPC 系列编程竞赛的 Rating 统计与展示系统。汇总正式赛、校内训练赛、OJ 平台三类数据，计算选手 Rating，提供可交互的 Web 应用。

> **技术路线（已采纳）**：Reflex（Python 全栈 Web）+ SQLite + Caddy 反向代理。
> 原 Vue 3 静态站方案已废弃。实施按 [13-实施路线图](13-实施路线图.md) 分五期推进。

## 2. 架构

```
┌─────────────────────────────────────────────────────────────┐
│  数据导入（本地 / CLI / Web 上传）                              │
│  raw/（人工投放 + import 写入）──import──▶ SQLite              │
│  保留 raw/ 作为可复现、可 diff、可进 Git 的数据源                  │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│  运行时（服务器）                                              │
│  Caddy ──reverse_proxy──▶ Reflex（FastAPI + WebSocket）       │
│  ├── 静态资源（编译产物）                                       │
│  └── /data/*.json（可选只读导出）                              │
│  Python 常驻  ✅  SQLite（WAL） ✅                             │
└─────────────────────────────────────────────────────────────┘
```

与旧架构的本质区别：线上有常驻 Python 进程和数据库，交互操作不再依赖 CLI。

**两条硬性分层规则**（详见 [01](01-开发环境与工程结构.md)）：

- **`xcpc_core` 绝不 `import reflex`** —— 业务层脱离 web 可运行，CLI、pytest、定时任务都依赖此保证。
- **`xcpc_web` 绝不写 SQL，也不承载业务规则** —— State 只做「读表单 → 调 `xcpc_core` → 转视图模型 → 写 state var」。

## 3. 数据流

```
raw/（人工投放 + import 脚本写入）
  │
  ▼
SQLite（运行时数据库，store 层读写）
  │
  ▼
data/public/（可选只读导出 / 备份快照）
```

- `raw/` 保留，承担「人工投放、可复现、可 Git」职责
- 数据流**单向**：`raw → DB`；反向只产出备份，不回写 raw
- 不再维护 `processed/` 中间层（其职责由 SQLite 取代）

## 4. 核心实体

| 实体 | 说明 |
|------|------|
| **选手（Player）** | Rating 计算主体，含 OJ 账号、别名 |
| **队伍（Team）** | 1–3 人，以队员集合识别同一性（与队名无关） |
| **比赛（Contest）** | 三类来源：`formal` / `training` / `oj`，formal/training 在存储层合表 |
| **参赛记录（Standing）** | 比赛中的成绩行，关联到选手/队伍 |
| **用户（User）** | 可登录绑定选手，角色分 member / admin |

## 5. 榜单

- **双榜模式**：仅正式赛 / 全部数据
- **时间维度**：生涯 / 赛年 / 赛季
- 筛选条件为服务端 state var，切换即重查，不再预生成文件矩阵

## 6. 技术选型

| 模块 | 选型 |
|------|------|
| Web 框架 | Reflex（Python 全栈，编译 React SPA） |
| 数据库 | SQLite（WAL 模式） |
| 数据模型 | Pydantic（DTO）+ SQLAlchemy（ORM），显式互转 |
| 认证 | `reflex-local-auth` |
| 部署 | Caddy `reverse_proxy` + systemd |
| 包管理 | `pyproject.toml`（统一打包，替代 PYTHONPATH hack） |
