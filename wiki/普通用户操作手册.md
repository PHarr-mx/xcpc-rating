# 普通用户操作手册

> 适用对象：未登录访客、已注册的普通用户（`member`）。  
> 本文按当前 Web 已实现功能编写，供功能验收时逐项操作。管理员功能请看 [管理员操作手册.md](管理员操作手册.md)。

---

## 1. 启动、访问与账号准备

### 1.1 启动服务

若服务尚未启动，在项目根目录执行以下命令：

```bash
cd xcpc_web
../.venv/bin/reflex run
```

启动成功后，在浏览器访问：

| 地址 | 用途 |
|---|---|
| `http://localhost:3000/` | Web 前端与榜单首页 |
| `http://localhost:8000/ping` | 后端存活探测（可选） |

完整环境安装与首个管理员创建方法见 [启动指南.md](启动指南.md)。

### 1.2 访问权限说明

| 功能 | 是否需要登录 | 普通用户是否可用 |
|---|---:|---:|
| 查看 Rating 榜单 | 否 | 是 |
| 注册账号 | 否 | 是 |
| 登录 / 登出 | 否 | 是 |
| 个人资料、提交绑定申请 | 是 | 是 |
| 修改本人 Handle、别名、OJ 账号 | 是，且绑定申请已获批准 | 是 |
| `/admin/*` 后台页面 | 是，且必须为管理员 | 否 |

未登录时，导航栏显示“登录”“注册”；登录后显示当前用户名、“个人资料”和“登出”。

## 2. 查看 Rating 榜单

### 操作步骤

1. 打开首页：`http://localhost:3000/`。
2. 确认页面标题为 **“XCPC Rating 榜单”**。
3. 在统计范围中选择需要的范围：
   - **全部**：查看全部可用榜单数据；
   - **入学年**：再选择具体入学年；
   - **赛季**：再选择具体赛季。
4. 如需定位选手，在搜索框输入选手 ID 或姓名的关键字。
5. 查看表格结果；可清空搜索或切换统计范围，确认列表随条件改变。

### 预期结果

榜单表格显示下列信息：

| 列 | 含义 |
|---|---|
| Rank | 当前筛选范围内的名次 |
| Player ID | 选手 ID，例如 `p001` |
| Name | 选手姓名 |
| Grade | 入学年 / 年级信息 |
| Rating | 当前 Rating 分数 |
| Events | 计入的 Rating 事件数量 |
| Recent Delta | 最近 Rating 变化 |

页面底部还会显示算法标识、数据版本和生成时间等元信息。

> **注意：** 当前页面显示的算法标识为 `placeholder_v0` 时，表示 Rating 公式仍是占位版本。该分数可用于验证页面的数据读取、筛选和展示，不应作为最终业务评级结论。

### 异常与检查

- 显示“没有符合条件的选手”或空表时，先清空搜索条件，再切回“全部”范围确认；若仍为空，说明当前数据库没有可展示的榜单数据。
- 搜索仅用于筛选页面已有的榜单记录，不会创建选手或修改数据。

## 3. 注册普通账号

### 操作步骤

1. 点击导航栏的 **“注册”**，或直接访问 `http://localhost:3000/register`。
2. 填写：
   - **用户名**；
   - **密码**；
   - **确认密码**。
3. 点击 **“注册”**。
4. 成功后等待页面显示提示并跳转到登录页。

### 预期结果

- 页面显示：**“注册成功！即将跳转到登录页…”**。
- 新注册账号默认角色为 `member`，不能访问后台管理页面。
- 可使用刚注册的用户名和密码在登录页登录。

### 异常与检查

- 若用户名已经存在、两次密码不一致或密码不符合认证组件要求，页面会显示红色错误提示；按提示修改后重新提交。
- 注册失败时不应生成可用的新账号。

## 4. 登录与登出

### 登录步骤

1. 点击 **“登录”**，或访问 `http://localhost:3000/login`。
2. 填写用户名和密码。
3. 点击 **“登录”**。
4. 登录成功后观察导航栏。

### 登录成功的预期结果

导航栏不再显示“登录”“注册”，而会显示：

- 当前登录的用户名；
- **“个人资料”**；
- **“登出”**。

普通账号登录后不应显示“后台概览”“选手管理”等后台导航项。

### 登录失败与登出

- 用户名或密码错误时，登录表单上方显示红色错误提示，且仍保持未登录状态。
- 点击导航栏 **“登出”** 后，应回到未登录状态，导航栏恢复“登录”“注册”。
- 登出后访问 `/profile` 或任意 `/admin/*` 页面，应被要求登录或被重定向。

## 5. 提交选手绑定申请

普通用户需要先绑定一名已存在的选手，才能维护自己的 Handle、别名和 OJ 账号。绑定不是自动完成的，必须由管理员审批。

### 前置条件

- 已注册并登录普通账号；
- 管理员已在选手名册中创建待认领的选手；
- 该选手未离队、未被其他用户绑定；
- 当前账号没有其他待审批的绑定申请。

### 操作步骤

1. 登录后点击导航栏 **“个人资料”**，或访问 `http://localhost:3000/profile`。
2. 在 **“绑定选手”** 卡片中打开 **“选择要绑定的选手”** 下拉框。
3. 选择自己的选手（显示格式为“姓名（player_id）”）。
4. 可选：在 **“申请理由”** 中填写身份说明，例如学号。
5. 点击 **“提交绑定申请”**。

### 预期结果

页面显示绿色提示，例如：

```text
已提交对 p001 的绑定申请，等待 admin 审批
```

管理员可在 `/admin/users` 的“待审批绑定”列表中看到该申请。

### 重要限制

- 同一普通账号一次只能有一条待审批申请。重复提交时会显示：

  ```text
  已有待审批的绑定申请，请等待 admin 处理
  ```

- 下拉列表不会显示离队选手、已被绑定的选手，以及当前账号已经申请过的选手。
- 若管理员驳回申请，用户可重新进入“个人资料”并提交新的申请。
- 若管理员批准申请，重新打开或刷新“个人资料”后，应改为显示“绑定信息”和“自助资料”。

## 6. 维护已绑定选手的自助资料

### 可修改与不可修改的字段

| 字段 | 普通用户能否修改 | 说明 |
|---|---:|---|
| 校内 ID | 否 | 只读 |
| 姓名 | 否 | 标有“admin 维护” |
| 年级 | 否 | 标有“admin 维护” |
| 状态 | 否 | 标有“admin 维护” |
| Handle | 是 | 可留空 |
| 别名 | 是 | 用逗号、中文逗号或换行分隔 |
| OJ 账号 | 是 | 可添加或删除 |

### 6.1 修改 Handle 与别名

1. 确认绑定申请已被批准，并进入“个人资料”。
2. 在 **“自助资料”** 中填写或修改 **Handle**。
3. 在 **“别名”** 中输入一个或多个别名，例如：

   ```text
   Acid, 神神
   ```

4. 点击 **“保存资料”**。

**预期结果：**页面显示绿色提示 **“资料已保存”**；刷新页面后填写内容仍应保留。

> 若 Handle 为空且别名也为空，点击保存会提示“没有需要保存的字段”。这不会修改已有资料。

### 6.2 添加 OJ 账号

1. 在 **“OJ 账号”** 区域选择平台：Codeforces、AtCoder、洛谷或牛客。
2. 在“OJ 用户名”输入框填写账号。
3. 点击 **“添加”**。
4. 检查该账号是否出现在账号列表中。

**预期结果：**页面显示绿色提示 **“OJ 账号已添加”**，列表中显示平台标签、账号名和“删除”按钮。

### 6.3 删除 OJ 账号

1. 在已存在的 OJ 账号右侧点击 **“删除”**。
2. 检查账号是否立即从列表消失。

**预期结果：**页面显示绿色提示 **“OJ 账号已删除”**。

### 异常与检查

- 不填写 OJ 用户名直接点击“添加”会提示：`请填写 OJ 账号`。
- 同一平台下添加完全相同的账号会提示：`该 OJ 账号已存在`。
- 字段格式或数据校验失败时，以页面红色提示为准；修正后重新操作。
- Handle、别名和 OJ 账号的改动会直接写入当前绑定选手资料；测试时请使用专门的测试账号 / 测试选手，避免覆盖真实资料。

## 7. 普通用户验收清单

可按以下顺序完成一次完整验收：

- [ ] 未登录访问 `/`，能看到榜单页面和“登录”“注册”。
- [ ] 修改榜单统计范围、具体周期和搜索关键字，结果或空态会正确变化。
- [ ] 注册一个新的测试账号；成功后可跳转登录。
- [ ] 用测试账号登录；导航栏显示用户名、个人资料和登出。
- [ ] 在“个人资料”中对一个测试选手提交绑定申请，看到“等待 admin 审批”的成功提示。
- [ ] 管理员批准申请后，刷新普通用户的“个人资料”，出现绑定信息和自助资料。
- [ ] 修改 Handle / 别名并保存，刷新后信息仍存在。
- [ ] 添加一个 OJ 账号，再删除它；两次操作均出现成功提示并即时反映在列表中。
- [ ] 点击登出；普通用户后台导航消失，访问个人资料时不再能编辑。
