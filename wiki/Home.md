# 校内 XCPC Rating 系统

校内 XCPC 系列编程竞赛的 Rating 统计与展示系统。数据层 SQLite 持久化，Web 层 Reflex 全栈。

> **本文档定位**：面向**二期开发与运维**的技术文档。描述**系统当前是什么、怎么改、怎么部署**。
> 已完成的开发进度、里程碑过程、决策讨论记录不在本处↔见 Git 提交历史。

## 快速开始

```bash
source ./setup_env.sh                              # uv sync + 激活 .venv
uv run python -m pytest xcpc_core -v               # core 测试
cd xcpc_web && ../.venv/bin/reflex run             # 开发服务器（3000）
```

详见 [开发指南](开发指南)。

## 核心约束（三句话）

1. **`xcpc_core` 绝不 `import reflex`** —— 业务层必须能脱离 Web 运行（CLI / pytest）
2. **`xcpc_web` 绝不写 SQL、不承载业务规则** —— State 只做「读表单 → 调 core → 转视图模型」
3. **禁止绕过 `*.api` 直接读写存储** —— 否则约束失效、缓存不失效、审计缺失

违反任一条，后续换框架、加 CLI、加定时任务都要重写。
