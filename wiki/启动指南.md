# 启动指南

> 校内 XCPC 编程竞赛 Rating 系统 · Python 3.13 + uv + Reflex 0.9.7 + SQLite

本文只讲「怎么跑起来」。项目结构、架构、开发约定见 [Home](Home) 与其下的技术文档。

---

## 1. 前置要求

- **uv**（Python 包管理器）：`brew install uv`
- **Python 3.13**（由 `.python-version` 锁定，uv 会自动安装）
- 无需手动装 node/bun——Reflex 首次运行时自动初始化前端依赖

## 2. 安装依赖

在项目根目录：

```bash
uv sync --extra web     # 核心 + Web 依赖（reflex、reflex-local-auth）
```

> 也可 `source ./setup_env.sh`（等价于 `uv sync` + 激活 `.venv`），但它**不带** `--extra web`，
> 跑 Web 前仍需补 `uv sync --extra web`。

## 3. 启动 Web 开发服务器

```bash
cd xcpc_web
../.venv/bin/reflex run
```

- 首次运行会自动编译并安装前端依赖（`reflex.lock/`），需要一点时间
- 启动成功后：
  - 前端：<http://localhost:3000>
  - 后端 API：<http://localhost:8000>（`/ping` 可探测）
- 停止：`Ctrl+C`。端口被占用时 `lsof -ti tcp:3000 | xargs kill`（8000 同理）

> 首次启动可能出现 `Database is not initialized` 警告——跑一次第 4 步的
> `create_admin.py` 即可建表消除。

## 4. 创建首个管理员

系统**不开放自助注册**，账号一律由管理员创建。首个 admin 需用 CLI 建：

```bash
cd xcpc_web
../.venv/bin/python create_admin.py --username admin --password 你的密码
```

它会自动建表（`data/db/xcpc_web.db`）并在同一事务内写入 `localuser` + `userprofile(role=admin)`。

密码重置：`--reset-password`（同时使旧会话失效）。

> ⚠️ 首次建库后请立即设足够强的密码；此后用管理后台批量开通成员账号。

## 5. 访问入口

| 路径 | 说明 | 权限 |
|------|------|------|
| `/` | 榜单 | 公开 |
| `/about` | 数据与赛季说明 | 公开 |
| `/players/{id}` | 选手详情 | 公开 |
| `/contests/{id}` | 比赛详情 | 公开 |
| `/login` | 登录 | 公开 |
| `/register` | 建号（**仅管理员**） | admin |
| `/profile` | 我的资料、OJ 账号、绑定申请 | 登录用户 |
| `/points` | 生涯积分（提交认证 + 双榜） | 登录用户 |
| `/admin` | 管理后台入口 | admin |

管理后台含 10 页：概览 / 用户审批 / 选手 / 队伍 / 比赛 / 赛事等级 / 积分认证 / 权重试算 / 在线导入 / 审计日志。

## 6. 数据位置

| 路径 | 说明 |
|------|------|
| `data/db/xcpc.db` | 核心业务库（选手/队伍/比赛/成绩/积分） |
| `data/db/xcpc_web.db` | Web 认证库（`localuser`/`localauthsession`/`userprofile`/`bindingrequest`） |
| `data/raw/formal/` | 正式赛导入归档（xlsx 写回） |
| `data/raw/contests/` | 通用比赛导入归档（JSON 写回） |
| `data/raw/players/`、`teams/` | 名册（一次性迁移源） |
| `data/config/` | `contest_weights.yaml`、`school.yaml`（可选 `rating_params.yaml`） |

`data/db/` 与 `logs/` 已 gitignore；`data/raw/` 可进 Git（可 diff 可复现）。

## 7. 常用命令

```bash
# 测试（根目录 + web 目录，两套分开跑）
uv run python -m pytest xcpc_core -v
cd xcpc_web && ../.venv/bin/python -m pytest tests -v

# 选手 / 队伍 CLI（根目录）
python -m xcpc_core.player.cli list --visible-only
python -m xcpc_core.player.cli get p001 --json
python -m xcpc_core.team.cli list
python -m xcpc_core.team.cli find --members p001 p002

# 通用比赛 JSON 导入
python -m xcpc_core.importer.cli template --entity team   # 打印模板
python -m xcpc_core.importer.cli import 模板.json --dry-run
python -m xcpc_core.importer.cli import 模板.json

# 一次性灌数据（幂等）
uv run python -m xcpc_core.db.migrate
```

正式赛 xlsx 导入用 Web `/admin/import`，或 Python API `importer.import_formal_xcpcio_xlsx`。

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| `uv sync --extra web` 失败 | 确认 uv 已装、网络可用；依赖锁在 `uv.lock` |
| `reflex run` 报端口占用 | 杀掉 3000/8000 残留进程 |
| `Database is not initialized` | 跑一次 `create_admin.py` 触发建表 |
| 想重置认证库 | 删 `data/db/xcpc_web.db` 后重跑 `create_admin.py` |
| 页面能打开但所有交互失效 | `api_url` 配置问题（见 [部署运维](部署运维) §3） |
| 改了 `rxconfig.py` / 主题不生效 | 这些**不会热重载**，必须重启服务 |
