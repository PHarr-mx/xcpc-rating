# 启动指南

> 校内 XCPC 编程竞赛 Rating 系统 · 技术栈：Python 3.13 + uv + Reflex 0.9.7 + SQLite
> 更新时间：2026-08-18（二期认证 P2a–P2c 完成后）

本文档只讲「怎么跑起来」。项目结构、架构、开发约定见 `AGENTS.md` / `README.md` / `docs/`。

---

## 1. 前置要求

- **uv**（Python 包管理器）：`brew install uv`
- **Python 3.13**（由 `.python-version` 锁定，uv 会自动安装）
- 无需手动装 node/bun——Reflex 首次运行时自动初始化前端依赖

## 2. 安装依赖

在项目根目录：

```bash
uv sync            # 核心业务层依赖
uv sync --extra web   # 追加 Web 依赖（reflex、reflex-local-auth）
```

> 等价地，也可以 `source ./setup_env.sh`（它会 `uv sync` + 激活 `.venv`，但**不带** `--extra web`，所以跑 Web 前仍需 `uv sync --extra web`）。

## 3. 启动 Web 开发服务器

```bash
cd xcpc_web
../.venv/bin/reflex run
```

- 首次运行会自动编译并安装前端依赖（`reflex.lock/`），需要一点时间
- 启动成功后：
  - 前端：<http://localhost:3000>
  - 后端 API：<http://localhost:8000>（`/ping` 可探测）

停止：`Ctrl+C`。端口被占用时先 `lsof -ti tcp:3000 | xargs kill`（8000 同理）。

## 4. 创建首个管理员

认证（二期）已就绪，注册的用户默认是 `member`，首个 admin 需用 CLI 创建：

```bash
cd xcpc_web
../.venv/bin/python create_admin.py --username admin --password 你的密码
```

它会自动建表（`data/db/xcpc_web.db`）并在同一事务内写入 `localuser` + `userprofile(role=admin)`。

## 5. 访问入口

| 路径 | 说明 |
|------|------|
| `/` | 榜单只读页（P1） |
| `/register` | 注册（注册成功后自动写入 UserProfile，跳转登录） |
| `/login` | 登录 |
| `/profile` | 个人资料：绑定申请 + 自助维护 handle/别名/OJ 账号（P2d，未登录跳转登录） |
| `/admin/*` | 二期后续 Part（P2e/P2f）开发中 |

## 6. 数据位置

| 路径 | 说明 |
|------|------|
| `data/db/xcpc.db` | 核心业务库（选手/队伍/比赛/rating/board） |
| `data/db/xcpc_web.db` | Web 认证库（`localuser`/`localauthsession`/`userprofile`/`bindingrequest`） |
| `data/raw/` | 原始 JSON（可进 Git，import 写回归档） |
| `data/config/` | `contest_weights.yaml`、`school.yaml` 等配置 |

## 8. 常见问题

- **`uv sync --extra web` 失败**：确认 uv 已安装、网络可用；依赖锁定见 `uv.lock`。
- **`reflex run` 报端口占用**：杀掉 3000/8000 残留进程再启动。
- **提示 `Database is not initialized`**：`create_admin.py` 或首次注册会触发建表；也可先跑一次 `create_admin.py` 完成建表。
- **想重置 Web 认证库**：删除 `data/db/xcpc_web.db` 后重新运行 `create_admin.py`（会重新建表）。
